# Job Search Toolkit

A personal suite of AI-powered tools to streamline the job search process —
built to support a career transition from technical support and business
intelligence into data analytics and cybersecurity.

## Tools

| Tool | Status | Description |
|------|--------|-------------|
| `resume_tailor` | In Progress | Paste a job description, get a tailored resume back |
| `interview_prep` | Planned | Generate likely interview questions from a JD |
| `job_tracker` | Planned | Track applications, statuses, and follow-ups |
| `job_feed` | Planned | Aggregate remote job listings matching target roles |
| `company_research` | Planned | Auto-generate a company brief before interviews |

## Setup

1. Clone the repo
2. Copy `.env.example` to `.env` and add your API keys
3. Install dependencies: `pip install -r requirements.txt`
4. Run any tool from its directory

## Requirements

- Python 3.9+
- Anthropic API key (Claude)
